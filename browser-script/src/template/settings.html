Position du panneau

Pour savoir combien de personnes utilisent le script et quels overlays sont les plus chargés.

Envoyé : version du script, langue et taille de l'écran, nom des overlays que vous chargez. Les overlays perso sont comptés sans leur URL.

Jamais envoyé : vos pixels, vos coordonnées, votre compte ZEvent. Pas de cookie ; votre IP sert seulement à compter les visites uniques côté serveur, elle n'est pas conservée. Statistiques auto-hébergées, jamais partagées.
